# Sparkles / Bokeh effect images

Add **real images** of lights, bokeh, or sparkles here so the "Sparkles" background effect uses them instead of drawn circles (which can look like blinking).

## What to add

- **Format:** PNG (with transparency) or SVG.
- **Names:** `1.png`, `2.png`, `3.png`, … up to `8.png` (and/or `1.svg`–`4.svg`).
- **Content:** Soft bokeh circles, light flares, sparkle textures, fairy lights, or similar. Transparent background works best.

## Where to get free images

1. **Pexels** – https://www.pexels.com/search/bokeh%20png/ or "light bokeh", "sparkle overlay"
2. **Pixabay** – https://pixabay.com/images/search/bokeh/ (filter: Transparent)
3. **Unsplash** – search "bokeh" or "light leak"; use PNG with transparency if available
4. **FreePNGimg / PNGTree** – search "bokeh PNG transparent" or "sparkle overlay PNG"

Download 5–10 different images (various sizes and softness), then rename them to `1.png`, `2.png`, etc. and place them in this folder. The app will load all of them and use them randomly for the sparkles effect.

If no images are present, the effect falls back to a softer drawn style (no blinking).
